# Application icon

DataCraft uses one minimalist white database cylinder on a cobalt rounded square. The project menu,
About dialog and native window share the same mark. The UI uses 32/64 px variants
for crisp small controls; native windows use `assets/icon.png`. Windows executables
embed `assets/icon.ico`; macOS bundles use `assets/DataCraft.icns`.

The committed assets, including `assets/icon.svg`, are generated together:

```sh
python -m pip install Pillow
python scripts/make_icon.py
python scripts/make_icon.py --check
```

Python is only needed to regenerate assets. The Windows ICO includes 16, 20, 24,
32, 40, 48, 64, 128 and 256 px images. `build.rs` compiles the icon resource during
normal Windows builds and fails if the resource cannot be embedded. Native MSVC
builds need the Windows SDK resource compiler. Cross-builds use their toolchain's
`windres` or `llvm-rc`; `RC` can override resource-compiler discovery.

The PNG and ICNS are regenerated by the same script on Windows, macOS or Linux;
the existing macOS bundle script copies the ICNS into the application bundle.
